# Hardware Requirements

- ESP32 development board
- DHT11
- MQ-2
- 0.96-inch SSD1306 OLED (128 × 64)
- Relay module
- Demonstration fan/load
- Breadboard
- Jumper wires
- USB programming/debugging cable
- Regulated power supply arrangement suitable for the actual prototype

## Safety
The prototype is intended for controlled laboratory demonstration. Do not connect hazardous/high-energy loads directly to ESP32 GPIO. Confirm the actual relay rating, load current, supply voltage/current and isolation arrangement before energizing the setup.
