# GitHub Submission Checklist

## Required technical items
- [x] Final circuit diagram/system schematic
- [x] Complete source code
- [ ] GitHub repository link added to final submission form
- [x] README with setup instructions
- [x] Hardware/software requirements
- [x] Experimental setup photographs
- [x] Step-by-step execution instructions
- [x] Test plan
- [x] Raw experimental data
- [x] Processed/calculated data
- [x] Results tables
- [ ] Graphs/charts where applicable — not appropriate for the single documented data point
- [x] Verification/validation results
- [x] Final prototype/software evidence
- [ ] Video demonstration link added to final submission form

## Before publishing
- [ ] Confirm circuit diagram matches the actual prototype.
- [ ] Confirm all source code is the final version.
- [ ] Confirm Wi-Fi/MQTT credentials are placeholders only.
- [ ] Confirm no passwords/API keys/tokens/private credentials are exposed.
- [ ] Add remaining official team members if this is a team repository.
- [ ] Add the final GitHub link to the submission form.
- [ ] Add the accessible Google Drive video link to the submission form.
- [ ] Test both links from an incognito window or another account.

## Important
Do not add invented experimental measurements, power ratings, sensor accuracy figures, MQTT latency values, packet-loss percentages, or reliability claims.
